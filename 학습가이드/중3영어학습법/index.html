과제에 적용하는 실천 순서

  1. 대상을 연결하기

    대명사 후보를 앞 문장에서 찾고 수와 의미가 맞는지 비교합니다. 가장 가까운 명사가 항상 답이라고 정하지 마세요.

  2. 문장 관계를 말로 쓰기

    연결어의 뜻만 외우지 말고 무엇과 무엇이 대조되거나 원인이 되는지 적습니다. 연결어가 없어도 내용으로 이어지는 경우가 있습니다.

  3. 핵심을 묶어 요약하기

    반복되는 대상과 변화한 내용을 한두 문장으로 정리합니다. 자신의 상식으로 내용을 덧붙이지 말고 본문에서 확인합니다.

  4. 서술형 조건에 맞춰 쓰기

    필수 낱말이나 시제 조건이 있으면 요약 내용과 함께 대조합니다. 교사가 준 피드백을 다음 문장에 적용해 보세요.

직접 해 보는 연습

because와 so가 잇는 원인·결과

“The playground was wet because it rained.”에서는 비가 온 일이 원인이고 운동장이 젖은 상태가 결과입니다. “It rained, so the playground was wet.”로 바꿔도 같은 관계를 나타냅니다. 단어 순서가 달라도 원인과 결과를 다시 찾으세요.
