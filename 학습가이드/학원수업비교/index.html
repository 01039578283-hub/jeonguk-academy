과제에 적용하는 실천 순서

  1. 현재 수행을 어떻게 보는지 묻기

    점수 외에 풀이 과정·읽기·쓰기와 필요한 도움을 확인하는지 질문합니다. 진단이라는 이름보다 어떤 자료를 보는지가 중요합니다.

  2. 설명 뒤 학생의 활동 확인하기

    설명을 들은 뒤 학생이 직접 해 볼 과제가 있는지, 막히면 어떤 피드백을 받는지 묻습니다.

  3. 과제와 소통 방식 확인하기

    숙제량을 어떻게 정하고 미완료나 반복 오류를 어떻게 다루는지 질문합니다. 보호자가 받는 보고의 내용과 주기도 확인하세요.

  4. 운영 조건을 문서로 대조하기

    학년·과목·횟수·시간·비용·별도 항목 등 실제 안내를 같은 기준으로 비교합니다. 확인하지 못한 내용은 미확인으로 남겨 직접 문의합니다.

직접 해 보는 연습

비교표를 확인한 내용으로 채우기

“개별 관리”라는 설명만으로 수업을 같거나 다르다고 판단하지 않습니다. 틀린 문제를 누가 언제 확인하고 학생이 다시 해 보는지 구체적인 과정을 물어보세요. 답을 받지 못한 칸을 추측으로 채우지 않습니다.

내 상황에 맞게 조정하기

상담에서 들은 설명은 날짜와 담당 지점을 함께 적습니다. 아직 시간표가 확정되지 않았거나 과목 운영을 확인 중이라면 그 상태를 그대로 남겨 재확인하세요. 학생에게 필요한 도움과 연결되는 질문 두세 개를 우선 확인하면 서로 다른 수업 안내를 비교하는 기준을 잡기 쉽습니다.

연습할 때 구분할 점

  • 다른 학생의 결과를 내 자녀의 보장된 결과로 해석하지 마세요.
  • 일반 브랜드 설명과 개별 지점의 운영 정보를 구분하세요.
